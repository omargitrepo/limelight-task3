# Omar Ebayah — Responsive Web Design Portfolio

A customized Bootstrap-based personal portfolio created for the LimeLight TechLead Responsive Web Design internship task.

## Requirements covered

- Responsive web design (desktop, tablet and mobile)
- 5+ website sections
- Past coding activity and projects
- Academic history and university experience
- Favourite activities, food, sports and interests
- Bootstrap foundation
- Custom HTML, CSS and JavaScript
- Mobile navigation
- Scroll progress indicator
- Scroll reveal animations
- Back-to-top button
- Project and skill cards
- Academic timeline

## Sections

1. Home
2. About
3. Academic Journey
4. Coding Activity / Projects
5. Toolbox / Skills
6. Favourites
7. Contact

## How to run

Simply open `index.html` in a browser.

For GitHub Pages:
1. Upload the complete project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select the `main` branch and `/ (root)`.
4. Save and open the generated GitHub Pages URL.

## Before submitting

Replace the placeholder links in the Contact section:

- `your-email@example.com`
- GitHub profile URL
- LinkedIn profile URL

## Technologies

HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons, Google Fonts.
